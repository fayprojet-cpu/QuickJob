# 💼 cabinet — Chatflow

Livrables pour le cabinet de conseil **Chatflow**.

## Flux
- **Inputs** (briefs client, données, comptes-rendus, contexte mission) →
  `context/import/cabinet/<projet>/`
- **Livrables** (rapports, présentations, recommandations, supports client) →
  `livrables/cabinet/<projet>/`

## Nommage
`AAAA-MM_nom-du-projet` en kebab-case — voir `livrables/README.md`.

Exemple : `2026-09_audit-process-client-x`

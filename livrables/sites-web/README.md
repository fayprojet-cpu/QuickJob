# 🌐 sites-web

Sites internet : landing pages, sites vitrines, front-ends d'applications.

## Flux
- **Inputs** (maquettes, textes, logos, chartes, références) →
  `context/import/sites-web/<projet>/`
- **Livrables** (code du site, exports, aperçus, doc de mise en ligne) →
  `livrables/sites-web/<projet>/`

## Nommage
`AAAA-MM_nom-du-projet` en kebab-case — voir `livrables/README.md`.

Exemple : `2026-09_landing-chatflow`

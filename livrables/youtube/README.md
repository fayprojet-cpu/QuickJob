# 🎬 youtube

Briefs vidéos, scripts, hooks et calendrier éditorial.

## Flux
- **Inputs** (idées, sujets, transcripts, références de chaînes, éléments de
  marque) → `context/import/youtube/<projet>/`
- **Livrables** (briefs, scripts, hooks, calendrier éditorial) →
  `livrables/youtube/<projet>/`

## Nommage
`AAAA-MM_nom-du-projet` en kebab-case — voir `livrables/README.md`.

Exemple : `2026-09_serie-lancement`

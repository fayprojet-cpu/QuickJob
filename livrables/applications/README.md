# 🛠️ applications

Outils, scripts et automatisations.

## Flux
- **Inputs** (cahier des charges, specs, exemples de données, accès/API) →
  `context/import/applications/<projet>/`
- **Livrables** (scripts, outils, automatisations + notice d'utilisation) →
  `livrables/applications/<projet>/`

## Nommage
`AAAA-MM_nom-du-projet` en kebab-case — voir `livrables/README.md`.

Exemple : `2026-09_export-notion-vers-csv`

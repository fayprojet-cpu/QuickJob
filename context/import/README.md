# 📥 context/import

Point d'entrée pour **tout ce que tu me fournis** : briefs, notes, exports,
captures, données, accès… la matière première dont j'ai besoin pour travailler.

## Comment déposer un input

Range chaque document dans le **thème** puis le **projet** concerné, avec le
même nom de projet que dans `livrables/` :

```
context/import/<thème>/<projet>/
```

Thèmes disponibles (identiques à `livrables/`) :
`sites-web/` · `applications/` · `youtube/` · `cabinet/` · `ecole/`

Exemple :

```
context/import/sites-web/2026-09_landing-chatflow/
    brief.md
    charte-graphique.pdf
```

Je te rends ensuite le résultat fini dans le dossier miroir :

```
livrables/sites-web/2026-09_landing-chatflow/
```

Voir `livrables/README.md` pour la convention de nommage complète.
